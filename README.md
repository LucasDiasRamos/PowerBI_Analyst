## About this repository

These projects were developed during learning activities in the **Power BI Analyst** training track. The repository brings together report files and exercise folders, showcasing a progression through data preparation and dashboard development.

This is a learning/project collection rather than a deployed analytics product.

## How to inspect the reports

1. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) if you want to open editable reports.
2. Download `Ex_Finance.pbix` and open it in Power BI Desktop.
3. Explore the measures, model, visualizations and report pages available in the file.
4. Alternatively, open the exported `Ex_Finance.pdf` directly on GitHub to preview the finished report.

Some reports may reference source files or connections from the original exercises. If a refresh fails, inspect the data source settings before reconnecting.
